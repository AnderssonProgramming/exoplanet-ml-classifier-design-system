Slide 08 · the equations behind the pipeline

Three equations carry the weight.

Logistic regression — log-odds
log P(y=1∣x)⁄(1−P) = β0 + β⊤x
Linear baseline · interpretable coefficients · weak under non-linear feature interactions.
SMOTE — synthetic minority sample
xnew = xi + λ(xnn − xi), λ ~ U(0,1)
Applied only when class ratio < 0.30 — KOI is already 49/51, so SMOTE is a no-op safety net.
Matthews correlation coefficient — robust under imbalance
MCC = (TP·TN − FP·FN) ⁄ √((TP+FP)(TP+FN)(TN+FP)(TN+FN))
Single-number summary of the confusion matrix · range [−1, 1] · 0 = random · we report it alongside F1 to stay honest about both classes.
